# PayloadEnhancer

This is an project i made where it runs your payload but with extra options such as persistence and self destruction (i will make more in the feature)

## Contents

## How does it work?

So to run it you run the following

powershell:
```
.\main.exe
```
CMD:
```
main.exe
```
run one of these to run it then you have 3 options 
1. Add persistence 
2. Add self destruction
3. Quit

## What is persistence 
Persistence basically is when the pc starts up the file runs

## Which file to run
So which file do you run so you run the payload.exe since it will run your .exe or whatever file with the extra options selected!
